# Apache Kafka カリキュラム - 第1章: 機能全体像

## Apache Kafkaとは

Apache Kafkaは、高スループット・低レイテンシーでリアルタイムのデータストリーミングを処理するための分散イベントストリーミングプラットフォームです。2011年にLinkedInで開発され、現在はApache Software Foundationのオープンソースプロジェクトとして管理されています。

## コアコンセプト

Kafkaは以下の3つの主要な機能を提供します：

1. **メッセージングシステム**: アプリケーション間で非同期にデータを送受信
2. **ストレージシステム**: データを永続化し、後から読み取り可能
3. **ストリーム処理**: リアルタイムでデータを変換・処理

## Kafkaの主要コンポーネント

### 1. Producer (プロデューサー)
- データをKafkaに送信するアプリケーション
- メッセージを特定のトピックに発行

### 2. Consumer (コンシューマー)
- Kafkaからデータを読み取るアプリケーション
- トピックを購読してメッセージを消費

### 3. Broker (ブローカー)
- Kafkaサーバー本体
- メッセージの受信、保存、配信を担当
- 複数のブローカーでクラスターを構成

### 4. Topic (トピック)
- メッセージのカテゴリ/フィード名
- ログとして永続化される
- 複数のパーティションに分割可能

### 5. Partition (パーティション)
- トピックの物理的な分割単位
- 並列処理とスケーラビリティを実現
- 各メッセージは順序を保証

### 6. ZooKeeper / KRaft
- クラスターのメタデータ管理
- ブローカーの調整とリーダー選出
- KRaftは新しいZooKeeper不要のモード

### 7. Consumer Group (コンシューマーグループ)
- 複数のコンシューマーをグループ化
- パーティションを分散して処理
- スケーラビリティと耐障害性を提供

## Kafkaエコシステム

### Kafka Connect
- 外部システムとKafkaを接続するフレームワーク
- Source Connector: 外部データをKafkaへ
- Sink Connector: Kafkaから外部システムへ

### Kafka Streams
- Kafkaに組み込まれたストリーム処理ライブラリ
- リアルタイムデータ変換・集計・結合

### ksqlDB
- SQLライクな構文でストリーム処理
- ストリーミングアプリケーションを簡単に構築

### Schema Registry
- メッセージスキーマの管理
- スキーマの進化とバージョン管理
- Avro、Protobuf、JSONスキーマをサポート

## Kafkaのユースケース

1. **リアルタイムデータパイプライン**
   - システム間のデータ移動と統合

2. **ストリーム処理**
   - リアルタイム分析とモニタリング

3. **イベントソーシング**
   - すべての状態変更をイベントとして記録

4. **ログ集約**
   - 分散システムからのログ収集

5. **メトリクス収集**
   - アプリケーションとインフラのメトリクス

6. **コミットログ**
   - データベースの変更履歴の追跡

## Kafkaの特徴

### 長所
- **高スループット**: 1秒間に数百万のメッセージを処理
- **スケーラビリティ**: 水平スケーリングが容易
- **耐障害性**: レプリケーションによるデータ保護
- **永続性**: ディスクへの永続化
- **リアルタイム**: 低レイテンシーのデータ配信
- **分散処理**: パーティショニングによる並列処理

### 考慮点
- **複雑性**: セットアップと運用に専門知識が必要
- **リソース**: メモリとディスクの要件が高い
- **学習曲線**: 概念の理解に時間が必要

## カリキュラムの進め方

このカリキュラムは、以下の順序でKafkaを学習します：

1. **技術的原理** - Kafkaの内部動作を理解
2. **Producer** - データ送信の基礎
3. **Consumer** - データ受信の基礎
4. **Topics & Partitions** - データ構造の理解
5. **Consumer Groups** - スケーラブルな消費
6. **Replication** - 耐障害性の実現
7. **Kafka Connect** - 外部システム連携
8. **Kafka Streams** - ストリーム処理
9. **ksqlDB** - SQLによるストリーム処理
10. **Schema Registry** - スキーマ管理
11. **Monitoring & Operations** - 運用とモニタリング

各レッスンでは、理論と実践を組み合わせて学習します。
